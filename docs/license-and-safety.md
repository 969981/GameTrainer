# 许可证、发布与安全边界

## 许可
本项目规划 Rust/Tauri/React、windows-rs 与可选 MinHook；代码引入前核验各依赖对应版本的 LICENSE 和 NOTICE。Emerald v5.3.0 CE Lua 资料的 GPL-3.0 来源需要单独处理，不因重写成 Rust 就自然消除版权/许可义务。对不确定的部分先记录来源和许可证约束，再决定是否移植、重写或独立实现。

## 数据
不上传或分发 ROM、游戏安装包、受版权保护资源、用户存档、内存 dump 和账号凭证。截图或虚拟游戏资料需核查使用许可。

## 运行时
默认只读；不支持绕过反作弊、隐蔽注入、自动提权、在线多人作弊。Native Agent 和 Hook 后置且仅在用户知情、受控的本地单机测试程序中使用。未知 build、Patch 冲突、所有权不明一律阻止写入。

## 开源策略
此仓库目前只提交原创规划与设计描述。实际实现前确定所采用的项目许可证并给各组件建立第三方许可清单。第三方旧源码与 ROM 不直接纳入本仓库。
