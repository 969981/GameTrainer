## 核心技术决策
- 技术栈：Rust + Tauri 2 + React/TypeScript/Vite + Tailwind CSS + shadcn/ui；状态管理 Zustand/TanStack Query。
- Win32 external memory + emulator bridge 并存，MinHook 仅作为未来可信 Native Agent 可选组件。
- 所有修改经预览、后端再次校验、执行和恢复；未知版本只读。
- 旧 Emerald Lua/CT 资料的 GPL-3.0 来源必须先完成许可证检查。
